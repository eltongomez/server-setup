## 🚀 Características Principais

- ✨ **Interface Interativa** - Menus coloridos e navegação intuitiva
- 🔒 **Hardening SSH** - Configuração segura de acesso remoto
- 🛡️ **Firewall UFW** - Regras de firewall customizáveis
- 🔐 **Fail2Ban** - Proteção contra ataques de força bruta
- 🔑 **Política de Senhas** - Requisitos de complexidade configuráveis
- 🔄 **Atualizações Automáticas** - Patches de segurança automáticos
- 🎯 **Hardening de Kernel** - Configurações de segurança via sysctl
- 📊 **Monitoramento** - Ferramentas integradas (htop, iotop, nethogs, ncdu, sysstat)
- 💾 **Backup Automatizado** - Script de backup com agendamento
- 📈 **Multi-Distribuição** - Ubuntu, Debian, CentOS, RHEL, Fedora

## 📋 Requisitos

- **Sistema Operacional**: Ubuntu 18.04+, Debian 10+, CentOS 7+, RHEL 7+, Fedora 30+
- **Privilégios**: Acesso root (sudo)
- **Shell**: Bash 4.0 ou superior
- **Espaço em Disco**: Mínimo 500 MB livres
- **Memória RAM**: Mínimo 1 GB (2 GB recomendado)
